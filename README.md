1.Работа с базой данных

Для проверки данных я подключался к базе данных scooter_rent через консоль с помощью psql.
Команда для подключения к базе данных:
psql -U morty -d scooter_rent### Подготовка тестовых данных

Задание 1 
Вывести логины курьеров и количество заказов, находящихся в доставке
SQL-запрос:
SELECT c."login", COUNT(o."track") AS orders_count
FROM "Couriers" c
JOIN "Orders" o ON c."id" = o."courierId"
WHERE o."inDelivery" = true
GROUP BY c."login";

У курьера самокат 4 заказа в доставке

Нужно вывести трекеры заказов и их статусы.

Статусы рассчитываются по условиям:

- если finished = true, статус равен 2;
- если cancelled = true, статус равен -1;
- если inDelivery = true, статус равен 1;
- во всех остальных случаях статус равен 0.

2. Автотест АPI
Автотест проверяет, что по треку заказа можно получить данные о заказе.
Тест сам создаёт заказ через API, сохраняет его трек и выполняет запрос

Как выполняется тест
1. Выполняется запрос на создание заказа.
2. Из ответа сохраняется номер трека заказа.
3. Выполняется GET-запрос на получение заказа по треку.
4. Проверяется, что код ответа равен 200.

Проект состоит.
- configuration.py — URL стенда и эндпоинты.
- data.py — тело запроса для создания заказа.
- sender_stand_request.py — функции для отправки API-запросов.
- create_order_test.py — автотест.
- .gitignore — список файлов и папок, которые не загружаются в репозиторий.
- README.md — описание проекта.
